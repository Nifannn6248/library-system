# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository ini
2. Jalankan `composer install`
3. Duplikat `.env.example` menjadi `.env` dan sesuaikan database
4. Jalankan `php artisan key:generate`
5. Buka proyek via Laravel Herd di browser
